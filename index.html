Products from JSON-LD <machvive-webmcp-products>

This page carries ordinary schema.org Product markup — the same JSON-LD a site already publishes so search engines understand its catalogue. The component reads it and exposes search_products, get_product and list_product_facets. Nothing was written by hand, and there is no backend.

Look at search_products in the inspector: its category and brand fields are dropdowns, because the allowed values were derived from this page's own data. An agent never has to guess a category name. The tools are read-only — they search and read, never add to a cart.
